# 國中數學教學助手

這是一個用來協助國中數學教學的專案，目標是讓老師在課堂上可以更方便地展示公式、圖形、範例題與教學內容。

## 專案目標

* 建立一個可在電腦與平板上使用的教學工具
* 整理國中數學公式與重點內容
* 支援圖片、公式、題目與教學說明
* 方便老師在課堂上直接使用

## 目前進度

* 已完成基本專案架構
* 已建立數學教學內容資料
* 已開始開發智慧圖庫系統
* 持續進行版本更新與除錯

## 專案資料夾說明

* `index.html`：主畫面
* `images/`：圖片資源
* `data/`：資料檔案
* `teaching-content/`：教學內容
* `imageLibrary.js`：圖庫功能程式
* `README.md`：專案說明文件

## 使用方式

1. 開啟專案資料夾
2. 用瀏覽器或本機伺服器執行 `index.html`
3. 依照畫面使用教學內容與圖庫功能
